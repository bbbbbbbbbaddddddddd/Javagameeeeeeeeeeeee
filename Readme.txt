Dodge — игра на Java Swing.
Игрок управляет треугольником внизу экрана и уклоняется от падающих красных блоков. За каждый блок, ушедший за экран, начисляется 10 очков. Скорость врагов постепенно растёт. При столкновении игра заканчивается, можно перезапустить.

Управление:
- Стрелка влево / клавиша A — движение влево
- Стрелка вправо / клавиша D — движение вправо
- Клавиша R — перезапуск после Game Over
- Мышь — движение игрока следует за курсором (mouseMoved / mouseDragged)

Запуск: скомпилировать все .java-файлы и запустить Main.
